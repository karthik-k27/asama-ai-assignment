Problem 1: Social Network for AI Agents (problem1_agent_social_network/)

Event-driven B2B agent network where enterprise agents (Swiggy, PhonePe, HDFC Bank, Bajaj Auto) publish updates and receive precision notifications via a 3-Stage Semantic Relevance Routing pipeline:

  • Stage 1 (SQL Guardrails): Filters inactive agents, self-posts, low-trust accounts (< 0.3), and blocked industries.
  • Stage 2 (Vector ANN): Queries Top-50 candidates via cosine similarity (HNSW in pgvector / runnable SQLite).
  • Stage 3 (Rerank & Gate): Scores cross-domain synergy, subscriptions, and closed-loop engagement feedback; notifies Top-5 (≥ 0.75).
  • Trust & Safety: Prompt-injection sanitization, strict data/prompt isolation, and HMAC-SHA256 signed webhooks.
  • Verification: All 4 tests in test_problem1.py pass (0.093s); Diwali post routed to PhonePe (0.9916) & HDFC Bank (0.9829) while dropping Bajaj Auto.

Problem 2: Local Linux Hardware Q&A Assistant (problem2_linux_hw_assistant/)

Local CLI assistant answering natural-language hardware questions using deterministic, read-only system inspection:

  • Strict Allow-List & No Shell Execution: Maps intent to pre-defined tool IDs (lscpu, lsblk -J, free -b, dmidecode -t memory, lspci -nn) via subprocess.run(..., shell=False); blocks shell metacharacters.
  • Permission & Hallucination Safeguards: Uses non-interactive sudo -n fallback for root-only DMI tables and normalizes stdout into typed JSON schemas so missing fields stay explicitly unknown.
